# Spill It or Sip It!

A mobile-first party game with a whole-group mode and a player-picking wheel. Open `index.html` in a browser to play locally. No install or build step is required.

## Publish on GitHub Pages

Push the repository to GitHub, then go to **Settings → Pages** and choose **GitHub Actions** as the build and deployment source. The included workflow deploys automatically on pushes to `main`. The expected URL is `https://yashteckchandani.github.io/SpillOrSip/` once Pages is enabled and the deployment succeeds.
